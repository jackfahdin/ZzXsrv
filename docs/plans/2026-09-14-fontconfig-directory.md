# Fontconfig Windows 目录枚举修复

基线：master `1bb897d4a368521e5aaab9e11c686c9c3ccebc20`。工作分支：`codex/fontconfig-20260914`。依据：[R4 发现的既有缓存重复问题](../validation/2026-09-14-font-dependencies.md)。

## 范围

修正 `third_party/fonts/fontconfig/src/fccompat.c` 的 Windows 目录读取顺序，使当前条目的名字和类型在返回前不被下一次搜索覆盖；修正同一 wrapper 的无效搜索句柄判断。保留 Fontconfig 2.16.0 和现有 API/构建配置，作为本地修正记录来源。使用现有独立工作区和候选验收流程，不 push。

## 测试边界

测试包括空目录、单文件、混合文件与子目录、带空格和较长的文件名、独立目录句柄、重复 EOF、不存在目录和文件冒充目录。使用本机正常临时文件，不写用户字体目录或缓存。缺失路径映射 ENOENT，其他打开失败保留原 EACCES 通用映射；不扩展为 Unicode 路径、长路径或所有 Win32 错误的重新设计。

此前被拒绝的 libXfont2 异常输入测试不属于本修复；其验证缺口保持原记录。
