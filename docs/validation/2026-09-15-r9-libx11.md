## 适配与验证设计

59 个继承差异与旧/新官方文件进行三方合并；`XKBAlloc.c`、`XKBMAlloc.c` 和 `x11.pc.in` 的旧改动已被上游吸收，不重复覆盖。保留 Windows DLL 导出、mhmake、文件/locale 处理、指针宽度转换及 XKB 服务器符号重命名。上游删除的 `src/os2Stubs.c` 不在 Windows 编译清单中。`src/config.h` 中遗留的 1.1.5 元数据同步为 1.8.13。

11 个根目录公共头与组件头内容一致，上游本次没有公共头内容变更，保留当前安装头。四份 NSIS 声明及历史 mkzip 增加 COPYING 和本地来源说明；本轮不运行安装或卸载。

新增五项真实 DLL 消费者检查：Caps Lock 和 Shift 的默认字母类型、默认小键盘、虚拟 Num Lock，以及命名/Unicode 键符转换。测试使用公开头、产品导入库和相邻的交付 DLL。产品未导出 XkbTranslateKeyCode/XkbFreeKeyboard，因此检查已导出初始化 API 返回的公开类型契约；每次进程只保留一个描述符至进程退出。

旧 R8 实际产物对照中，Caps Lock 层级和默认小键盘映射两项失败，另外三项通过，耗时 0.114 秒。初版测试曾引用未导出的 API 并假设初始化会设置 num_types；检查实际公开 API 后改为验证分配容量及类型内容，再确认上述两项真实旧行为失败。没有为升级扩大 DLL 导出集合。
