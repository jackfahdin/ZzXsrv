WinHTTP 使用系统自动代理发现，并关闭自动凭据发送。其代理设置不同于旧 libxml2 的环境变量代理。HTTPS、真实代理、认证挑战和重定向后的外部资源加载未做现场运行验收；本轮 HTTP 服务仅监听回环地址，输入均为自建正常 XML，不访问用户配置或启动配置中的程序。
