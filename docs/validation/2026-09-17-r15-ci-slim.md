## 简洁版（slim）剔除清单

`tools/package_release.py` 新增 `--edition full|slim`（默认 full）。slim 从 dist 剔除 13 项（相对 dist 根），字体全部保留：

| 剔除项 | 内容 |
| --- | --- |
| `swrast_dri.dll`、`swrastwgl_dri.dll`、`dxtn.dll` | Mesa 软件渲染链（软光栅 WGL 变体、S3TC 纹理压缩辅助） |
| `plink.exe` | SSH 转发助手（外部依赖） |
| `xlaunch.exe`、`libxml2.dll`、`libiconv.dll` | XLaunch 向导及其独占 XML 栈（libxml2/libiconv 仅被 xlaunch/xclock 引用，已核对保留二进制无依赖损失） |
| `xclock.exe`、`xcalc.exe`、`XClock`、`XClock-color`、`XCalc`、`XCalc-color` | 演示客户端及其 app-defaults 资源文件 |

剔除目标缺失时告警而非静默通过，上游改名不会使清单悄悄失效。Inno 脚本接受 `/DZxEdition` 与 `/DZxExcludes`，slim 安装包与 slim zip 文件集一致；两个版本共享一个 AppId，作为可选安装共存。ISCC.exe 解析顺序改为 `--inno` 参数、`INNO_SETUP_ISCC` 环境变量、PATH、旧默认路径，无固定安装位置的 CI runner 可用。

## CI 设计

- `.github/workflows/continuous-build.yml`：每日 16:00 UTC 及手动触发；快照 tag 已指向 origin/master 时自我跳过；windows-2025 上经 `scripts/build/buildall.ps1` 完整构建，跑 Python 测试套件，打包 full/slim 两个版本并以 rolling prerelease 发布。
- `.github/workflows/release.yml`：`v*` tag（semver 校验）或手动触发（仅构建）；preflight 先用 actionlint 自检工作流，release 作业发布 4 个产物加 `SHA256SUMS.txt` 为正式 GitHub Release。
- 工具链固定并校验哈希：Inno Setup 7.1.0（jrsoftware/issrc），及 runner 镜像不含的 NASM 2.16.03、WinFlexBison 2.5.25、GnuWin32 gperf 3.0.1（`scripts/ci/install-innosetup.ps1`、`scripts/ci/install-build-tools.ps1`）。
