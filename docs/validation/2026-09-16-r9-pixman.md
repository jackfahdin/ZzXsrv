## 来源与改动

从[官方发布目录](https://www.cairographics.org/releases/)取得 [Pixman 0.46.4](https://www.cairographics.org/releases/pixman-0.46.4.tar.xz)，下载 SHA-256 为 `a098c33924754ad43f981b740f6d576c70f9ed1006e12221b1845431ebce1239`；SHA-512 与同目录 `.sha512` 文件一致，未独立验证 PGP 签名。完整散列见 `third_party/graphics/pixman/source-files.json`。

归档的 207 个普通文件及 17 个相对符号链接全部纳入；Windows 中将链接物化为目标内容，并在清单保存原链接关系，共 224 文件。218 文件保留上游内容原始字节；6 个源码文件保留继承的 Windows 适配，补丁为 `patches/windows-adaptations.patch`，不把它们描述为本轮新发现的缺陷。另保留三个原生构建/配置文件，总计 227 个当前源码文件记录原始摘要。保留 IN 宏处理、梯形步进宽度、glyph hash 掩码、指针断言及 MMX/SSE2 调整，同时纳入上游 glyph 分配等改动。x64 仍使用 SSE2，未增加新指令集要求。

原目录声明 0.44.3，历史同步 SHA `aafb4caea2f440c8ca9fad2cfa2c2fb9e2779ae6` 未独立证实。与官方 0.44.2 的归档对比记录保留于本地证据，不能视作纯净 0.44.2。原生头和静态库实际报告 0.19.1；本次由官方模板生成 0.46.4 头并同步配置版本字段，保留其他特性宏。

原生构建补入 `pixman-filter.c` 和新版 `pixman-region64f.c`。前者原本已经有公共声明，但旧静态库未编译，正常消费者链接失败；后者是新版小数坐标区域实现。`pixman-region.c` 继续作为模板被包含。Pixman 静态链接进服务器，无独立 Pixman DLL。

四份 NSIS 声明及历史 mkzip 增加 Pixman COPYING、README.vcxsrv.md 两份交付文件；未执行安装卸载。主仓库及已验收 R9.2 目录保留。

## 专项验证

使用 test-driven-development 技能补充实际 MSVC 静态库消费者，断言独立已知的像素和区域结果。9 项测试覆盖版本与公开头一致性、预乘 alpha 混合及行尾保护、A8 遮罩、负源步长、nearest 缩放、目标裁剪、整数区域减法、新小数区域 API，以及卷积滤镜函数链接和实际绘制。前八项各在默认和禁用 SSE2/MMX 的独立进程运行；滤镜测试正常链接真实库并验证输出，均无协议或库行为 mock。

旧 R9.2 库下 9 项中六项通过，三项失败：版本不一致、小数 API 尚不存在及滤镜未链接；总计 5 个失败子项，0.782 秒。新版组件构建后 9 项通过，1.320 秒。前一次 8 项红灯记录也保留，不覆盖历史证据。这里的旧版小数 API 缺失是升级差异，不作为旧版故障。

新工作区的源码基线 433 项执行通过 46 项、缺少产物跳过 387 项，8.403 秒，不能当成完整产品回归。
