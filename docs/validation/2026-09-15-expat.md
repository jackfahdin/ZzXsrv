## 实际使用配置与范围

旧评估把 Mesa `xmlconfig.c` 中存在 Expat API 调用等同于实际启用，现更正：`src/util/makefile` 未定义 `WITH_XMLCONFIG`，源码的 Windows 构建走 `parseStaticConfig` 分支。Mesa 顶层 makefile 仍将 `libexpat.lib` 列为静态依赖，但这不能证明最终 DLL 包含或调用 Expat 解析器。本次保留该构建关系和静态配置行为，不启用外部 drirc XML，也不升级 Mesa。

旧 2.6.2 产物的实际独立链接报 `LNK2001 arc4random_buf`：根目录 `expat_config.h` 定义了 `HAVE_ARC4RANDOM_BUF=1`，旧 `xmlparse.c` 优先选择该 Unix 随机源。这解释了为何仅重建整包不足以验证此库可用；本轮增加直接链接生产静态库的运行检查。

采用有界升级：官方 Expat 2.8.4 完整来源、独立 Windows 配置、保持 mhmake 输出映射、补齐许可证打包、直接库检查及完整产品回归。Windows 配置保留窄字符、DTD、一般实体、命名空间和 1024 上下文字节；不启用 XML_UNICODE、XML_LARGE_SIZE、XML_ATTR_INFO。用上游 `random_rand_s.c` 获取 Windows 随机数，无 Unix 随机源宏。
