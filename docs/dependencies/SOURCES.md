## 实际导入起点

本项目从原 VcXsrv 的固定提交 [`d0a1eaf7ee15fcdf4f683388a88fec49078e6408`](https://github.com/marchaesen/vcxsrv/tree/d0a1eaf7ee15fcdf4f683388a88fec49078e6408) 继承整合源码，本地初始提交为 `e13a9d52d43c447d402932e89fcb3db9e177093b`，两者文件树相同。没有另行逐包下载全部依赖；下表“继承源码”才是这次导入的实际固定链接，“原始上游”表示组件作者的仓库、发行包或原源码记录的入口。

原作者发行说明记录的同步 commit 可以用于追溯，但目录内还含 VcXsrv 和本项目的改动，不能据此声称整目录等同于纯净上游。只有版本号的条目明确标为版本声明，不补造 tag 或精确 commit；原下载日志缺失的条目不补造下载日期。官方链接按原始元数据记录，并非全部已独立联网核验或逐字节比对。

范围包括主目录组件、可识别的嵌套代码与头文件、40 个字体来源包和工具；可选下载声明及外部工具另列，不能把它们当作已纳入或已参与 Windows 构建的依赖。混合片段不能识别到独立版本时，保留固定继承树、版权头和未知状态。本目录不是所有平台配置的传递依赖锁文件。
